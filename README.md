# Yo-kai Watch 4++ Save Converter

A save converter for **Yo-kai Watch 4++** (妖怪ウォッチ4 ぷらすぷらす). Converts saves between the Nintendo Switch and PS4 formats. Everything runs in the browser, no files leave your device.

## Usage

1. Drop a save folder. One side is enough.
2. Hit **Convert** and unzip the result. The README inside explains where it goes.

The tool auto-detects the platform.
